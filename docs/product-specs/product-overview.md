# MythicFrame – Product Overview

## What is MythicFrame?
MythicFrame is a browser-based design tool tailored to card games. It allows users to easily create card illustrations, frames, and full card layouts using Google Gemini to generate art that matches user-specified styles.

## Target Audience
- Card game designers
- Indie developers
- TCG/CCG creators

## Game Developer Focus (Narrative & Mechanics)
MythicFrame is designed to build **coherent card sets** that fit a specific game loop and story, not just isolated images.
- **Project-Level Game Context**: Define your setting (e.g., "Cozy Alchemy Shop"), tone, and visual constraints once. All generations respect this "world bible."
- **Card Roles**: Define if a card is an "Attack", "Resource", or "Event".
- **Story-Aware Prompts**: The AI understands that a "Potion" card in a "Cyberpunk" game looks different than in a "High Fantasy" game.

## Key Differentiators
- **Style Learning**: Analyzes references to replicate style.
- **Accurate Sizes**: Production-ready exports (1K, 2K, 4K).
- **Export w/ Prompts**: Metadata preservation.
- **Context-Aware**: Generates art that fits your specific game world.

## Main Modes
1. **Frame Mode**: Frames & borders only.
2. **Illustration Mode**: Card art only (Character/Scene) with Game Context support.
3. **Full Card Mode**: Complete card composition with mechanic-aware suggestions.
