# Social Media Copywriting for Developer Tools & Software

This skill provides instructions, formulas, and structural templates for crafting compelling, high-converting social media posts across major platforms.

---

## 1. Universal Rules & Algorithmic Guardrails

1. **Zero Outbound Links in Main Posts**:
   - Major platform algorithms (LinkedIn, X, Facebook) heavily downrank posts containing external links.
   - **Always** place the GitHub repository, documentation, or product link in the **first comment / reply**.
   - Conclude the main post with a clear, concise directional pointer:
     - X: `Link in 1st comment`
     - Bluesky: `Link in first reply`
     - LinkedIn: `(Repository link in the first comment)`
     - Facebook: `Project link and instructions are in the first comment.`
2. **Zero Emojis by Default**:
   - Maintain a serious, authentic developer/engineer aesthetic. Avoid emoji saturation. Only introduce emojis if explicitly requested by the user.
3. **Show, Don't Fluff**:
   - Highlight concrete technical specifications and capabilities (e.g., "100% local", "2-bone Inverse Kinematics", "Model Context Protocol integration") rather than generic marketing hyperbole.
4. **General-Purpose Positioning**:
   - When presenting specialized creative tools, emphasize that while the tool excels at its primary domain (e.g., 2D game assets, character sheets), it is versatile and serves any project needing visual reference consistency and refined prompting.
5. **Always Pair with Visual Evidence**:
   - Text alone performs poorly. Recommend attaching 1–2 high-fidelity visual assets (e.g., Studio UI screenshot + GitHub README capture).

## 2. Platform Guidelines & Templates

### A. X (Twitter)
- **Character Constraint**: Maximum 280 characters (standard free tier).
- **Format**:
  ```text
  [Strong Hook / Announcement]
  [Core value proposition: 100% local, open-source, key differentiator]

  [Excels at X, but built for ANY workflow needing Y]:
  - Key bullet 1
  - Key bullet 2

  Link in 1st comment
  ```
- **Example**:
  ```text
  Introducing MythicFrame
  100% local, open-source AI creative studio.

  Excels at game assets & characters, but works for ANY project needing reference consistency and refined prompting:

  - Use your own API keys OR browser accounts
  - Zero-key multi-account mode

  Link in 1st comment
  ```

---

### B. Bluesky
- **Character Constraint**: Maximum 300 characters.
- **Format**:
  ```text
  [Title / Announcement]
  [Value proposition]

  - Bullet 1
  - Bullet 2
  - Bullet 3

  Link in first reply
  #tag1 #tag2 #tag3
  ```
- **Example**:
  ```text
  Introducing MythicFrame
  The open-source 2D game asset studio running 100% locally on your machine.

  - Character bibles and sprite sheets
  - Pose Studio with real-time IK
  - Pixel art and outfit designer
  - Zero API key mode via browser bridge

  Link in first reply
  #gamedev #indiedev #ai
  ```

---

### C. LinkedIn
- **Character Constraint**: 1,200 – 2,500 characters.
- **Tone**: Professional, insightful, peer-to-peer technical sharing.
- **Structure**:
  1. **Hook**: Direct statement of what was built and why.
  2. **The Problem / Friction**: Address pain points (fragmented workflows, cloud subscriptions, prompt drift, broken poses, costly API usage).
  3. **The Solution**: How the local tool unifies the process.
  4. **Detailed Feature Highlights**: 5–7 bullet points with descriptive subheadings.
  5. **Privacy / Local-first stance**: No telemetry, no subscriptions, full ownership.
  6. **Call to Action**: Prompt discussion and point to the first comment for the link.
  7. **Relevant Hashtags**: 5–8 targeted industry tags.

---

### D. Facebook
- **Character Constraint**: 500 – 1,200 characters.
- **Tone**: Community-oriented, accessible, and structured.
- **Structure**:
  1. **Announcement & Value Pitch**: Clear headline.
  2. **Problem Addressed**: Relatable friction for creators/developers.
  3. **Key Highlights**: 4–6 concise bullet points.
  4. **Pointer to Visuals & First Comment**: Reference the attached images and link below.
  5. **Hashtags**: 4–6 tags.

## 3. First Comment / Reply Standard

For all platforms, use this standardized template for the first comment:

```text
GitHub Repository (100% Free & Open Source):
[REPO_URL]

If you find it helpful for your projects, feel free to give it a star on GitHub! Feedback, issues, and PRs are always welcome.
```
